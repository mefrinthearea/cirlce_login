# Circle Login Interface

A static login screen exploring decorative circular backgrounds and form composition.

## Features

Username and password fields, associated labels, decorative circles and custom typography.

## Technology

HTML, CSS and Google Fonts.

## Getting started

```sh
git clone https://github.com/mefrinthearea/cirlce_login.git
cd cirlce_login
```

Open `log_in/index.html` in a browser. No package installation or build step is required. External fonts or icons may require an internet connection.

## Entry point

`log_in/index.html`

## Scope and limitations

Visual prototype only; no authentication or backend. Use dummy values only.

## Project status

Early learning project retained to document development progress. Source reviewed for documentation; runtime behavior has not been re-tested in this update.
